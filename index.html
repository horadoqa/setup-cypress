Cypress

Para começar a trabalhar com Cypress, configure seu ambiente de desenvolvimento com as ferramentas abaixo.

Requisitos

No Windows, instale os seguintes recursos antes de começar a trabalhar com Cypress.

Node.js

Necessário para instalar, executar e gerenciar o Cypress e seus projetos.

→

Git Bash

Será utilizado como linha de comando para executar os comandos do projeto.

→

Visual Studio Code

Editor recomendado para desenvolvimento e criação dos testes automatizados.

→

Cypress

Framework utilizado para criação, execução e depuração dos testes.

→

Ambiente pronto?

Depois de instalar os requisitos, você estará pronto para configurar o Cypress e começar a criar seus primeiros testes automatizados.
